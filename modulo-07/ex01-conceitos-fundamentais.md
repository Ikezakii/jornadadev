Exercício 1 — Conceitos fundamentais ⭐ 🧠 (obrigatório)
Responda com suas palavras (2 a 4 linhas cada):

a. Qual é a função do AppServer?
b. O que é o RPO?
c. Para que serve o Configurador (SIGACFG)?
d. Qual a diferença entre campo Real e campo Virtual no SX3?


Respostas 

a -> Ele é o servidor que processa o código e conversa com o banco de dados

b -> É o banco de dados de fontes e programas do Protheus

c -> É o configurador, utilizado para gerenciar usuários, grupos, menus, permissões, parâmetros, dicionário de dados e configurações do sistema.

d -> O campo real é gravado fisicamente no banco de dados (Gravado nas colunas e é um dado persistente) e o campo virtual não é gravado em nenhuma coluna do banco de dados e existe apenas na interface e na lógica do sistema
